Every service that calls the API needs its own token. Tokens are scoped to one project and carry the permissions of the person who made them, never more.

Create a token under Settings, Tokens. Copy it once: it is not shown again. Send it in the Authorization header as a bearer token.

Tokens last 90 days. Rotate them before they expire; the old token keeps working for 24 hours after a new one is made, so deploys do not have to be timed to the second.
