## When to use it

<div class="dodont">
  <div class="start-card" style="min-height:0">
    <span><span class="t">Use a select to</span><span class="d">Pick one value from five to fifteen options people scan by name. Save space when all the options do not need to be visible. Submit a value with a form, or restore one on reset.</span></span>
  </div>
  <div class="start-card" style="min-height:0">
    <span><span class="t">Use something else when</span><span class="d">There are two or three options: use radios or a toggle group. People need to search a long list: use the command palette. People pick several values: use checkboxes.</span></span>

## Keyboard

The keys follow Radix Select. Focus moves onto the options, and returns to the trigger when the list closes.

| Where | Key | What happens |
| --- | --- | --- |
| Trigger | Enter, Space, Down, Up | Opens the list and focuses the chosen option. |
| Trigger | A letter | Picks the first matching option without opening. |
| List | Down and Up | Moves to the next or previous option. Disabled options are skipped. |
| List | Home, End | Moves to the first or last option. |
| List | Page Up, Page Down | Moves ten options. |
| List | Enter, Space | Picks the focused option and closes the list. |
| List | Escape | Closes the list and returns focus to the trigger. |
| List | A letter | Jumps to a match. Letters typed within a second make a longer prefix. |
| List | Tab | Held inside the list until it closes. |
| Mouse | Press, drag, release | Press the trigger, drag onto an option and let go to pick it. |

## Screen readers

- The trigger is a button with `role="combobox"`, `aria-expanded` and `aria-controls`. Its name is the visible label.
- The list is a `listbox` of `option` elements. The chosen one has `aria-selected="true"`. Dividers are hidden from the accessibility tree.
- Always give the select a visible label. With none, set `aria-label` on the element.
- A required select that is left empty reports "Please select an item in the list." through the form.

<Aside type="note" title="What it gives up">
  There is no native mobile picker, and the chosen option does not sit over the trigger (Radix's item-aligned position). Only the popper position is built.
</Aside>
