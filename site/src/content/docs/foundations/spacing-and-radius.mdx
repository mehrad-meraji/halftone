Corners are sharp but not square: 2, 6 and 10 pixels. Borders are always one pixel.

| Token | Value | Used for |
| --- | --- | --- |
| `--ht-radius-sm` | 2px | Keys, small chips |
| `--ht-radius-md` | 6px | Buttons, fields, menu rows |
| `--ht-radius-lg` | 10px | Cards, dialogs, panels |

## Shadows

| Token | Used for |
| --- | --- |
| `--ht-shadow-xs` | Resting controls |
| `--ht-shadow-sm` | Raised cards and toasts |
| `--ht-shadow-md` | Floating panels: menus, popovers, dialogs |
