Halftone is a library of web components for product interfaces. Every control is a custom element with an `ht-` tag, styled by CSS variables, and it works in any framework or none.

  <TabItem label="Principles">

These decide what ships and what gets said no to. Each one is written in the decisions log with the date it was made.

1. **Native first.** Dialogs sit on the native dialog element, overlays on the popover API, and fields are form-associated custom elements. The browser keeps the focus trap, the top layer and the form.
2. **Tokens, not forks.** Components read `--ht-*` variables and carry no hard-coded color. Changing a palette is a token change, never a component edit.
3. **Motion with a purpose.** Spring in, ease out faster. Motion shows where a panel came from, and `prefers-reduced-motion` turns all of it off. See [Motion](../foundations/motion/).
4. **Accessible as shipped.** Every story is checked with axe, and text keeps 4.5 to 1 contrast. A control that cannot be used from the keyboard is not done.
