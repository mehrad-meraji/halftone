## What you get

<div class="get-grid not-content">
  <div>
    <div class="num">01</div>
    <h3>Web components</h3>
    <p>{stats.components} components and {stats.elements} elements, from button to command palette. Built on Lit and TypeScript, one file each, and each file imports only `lit`.</p>
  </div>
  <div>
    <div class="num">02</div>
    <h3>Tokens, not forks</h3>
    <p>One set of `--ht-*` variables sets color, type, radius, shadow and motion. Point them at your own tokens and the library wears your brand.</p>
  </div>
  <div>
    <div class="num">03</div>
    <h3>Ways to ship</h3>
    <p>Install the package, copy one component file plus `tokens.css` into your app, or start from one of {stats.blocks} blocks: whole page sections in plain HTML.</p>
  </div>
</div>

These decide what ships and what gets said no to. Each one is written in the decisions log with the date it was made.

<div class="start-cards not-content">
  <div class="start-card" style="min-height:0">
    <span><span class="t">01 Native first</span><span class="d">Dialogs sit on the native dialog element, overlays on the popover API, and fields are form-associated custom elements. The browser keeps the focus trap, the top layer and the form.</span></span>
  </div>
  <div class="start-card" style="min-height:0">
    <span><span class="t">02 Tokens, not forks</span><span class="d">Components read `--ht-*` variables and carry no hard-coded color. Changing a palette is a token change, never a component edit.</span></span>
  </div>
  <div class="start-card" style="min-height:0">
    <span><span class="t">03 Motion with a purpose</span><span class="d">Spring in, ease out faster. Motion shows where a panel came from, and `prefers-reduced-motion` turns all of it off.</span></span>
  </div>
  <div class="start-card" style="min-height:0">
    <span><span class="t">04 Accessible as shipped</span><span class="d">Every story is checked with axe, and text keeps 4.5 to 1 contrast. A control that cannot be used from the keyboard is not done.</span></span>
  </div>
