# Getting Started

Halftone is a set of web components (`ht-*`). They work in plain HTML, React, Vue, Angular, Svelte, Laravel Blade, anywhere a browser runs.

## 1. Install

```bash
npm install @_mehrad/halftone
```

## 2. Load tokens, fonts and a component

```html
<link rel="stylesheet" href="/node_modules/@_mehrad/halftone/dist/tokens.css" />
<!-- Optional. Without these, system fonts are used. -->
<link href="https://fonts.googleapis.com/css2?family=Chakra+Petch:wght@500;600;700&family=Geist:wght@400;500;600;700&family=IBM+Plex+Mono:wght@400;500&display=swap" rel="stylesheet" />

<script type="module">
  import '@_mehrad/halftone/components/button/button.js'; // one component
  // import '@_mehrad/halftone'; // or everything
</script>

<ht-button variant="primary">Deploy It</ht-button>
```

`tokens.css` is required. Components read their colours, radii and fonts from it.

## 3. Theme it

Everything is a CSS variable. Override on `:root`, or on any wrapper to theme a subtree.

```css
:root {
  --ht-accent: oklch(0.7 0.18 200);
  --ht-radius-md: 0;
  --ht-halftone: none; /* remove the dot screen on headers */
}
```

Dark mode follows the OS. Force it with `<html data-theme="dark">` or `data-theme="light"`.

For deeper restyling, every component exposes `::part()` hooks:

```css
ht-input::part(control) { border-radius: 999px; }
```

## 4. Frameworks

| Framework | Notes |
|---|---|
| Plain HTML, Blade, Rails | Use the tags directly. |
| Vue | Add `isCustomElement: (tag) => tag.startsWith('ht-')` to the compiler options. |
| React 19 | Works as is. Pass events with `onClick` and properties as props. |
| Angular | Add `CUSTOM_ELEMENTS_SCHEMA` to the module or standalone component. |
| Svelte | Works as is. |

## 5. Forms

`ht-input` and `ht-button` are form-associated. They submit with `FormData`, reset with the form, and take part in `required` validation, with no wiring.

## Copy mode

Each component is a single file that imports only `lit`. If you want to own it, copy `src/components/<name>/<name>.ts` plus `tokens.css` into your project and edit freely. A `halftone add` command is planned.

## For agents

Read `custom-elements.json` (shipped in the package) instead of guessing. It lists every tag with its attributes, slots, CSS parts, CSS variables and events.

- Prefer the documented attributes. Don't reach into shadow DOM; use `::part()`.
- Labels use Title Case, sentences use sentence case (`Delete Project`, not `delete project`).
- Always give `ht-input` a `label`.
- Dialogs: open with `dialog.show()` or the `open` attribute; listen for `ht-close`. Put the primary action first in the footer.
